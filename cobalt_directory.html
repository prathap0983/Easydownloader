cobalt.directory

cobalt.directory is an unofficial site to track cobalt instances that are safe to use & what services work on them. This site updates every ~10 minutes.

This site is not 100% accurate! Some requests fail randomly, so always try the service regardless. This site gives an overall idea of what's working.

There are 2 lists, official and community below. You can also search by service, read the FAQ, or learn about the site.
